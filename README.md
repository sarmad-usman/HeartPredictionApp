# ❤️ Heart Disease Prediction Web App

A machine learning-powered web application that predicts the likelihood of heart disease using key medical parameters. Built with **Streamlit**, **scikit-learn**, and **Python**, this app provides real-time predictions, personalized health insights, and downloadable reports.

---

## 🚀 Features

- 🔍 **Real-Time Prediction**  
  Instantly predicts heart disease risk based on user input.

- 🧠 **Machine Learning Model**  
  Trained using reliable medical datasets with **scikit-learn**.

- 📊 **User-Friendly Interface**  
  Interactive UI built with **Streamlit**.

- 💡 **Personalized Advice**  
  Provides health suggestions based on prediction results.

- 📄 **Downloadable PDF Reports**  
  Generate and download detailed reports for future reference.

---

## 🛠️ Tech Stack

- **Frontend & Backend:** Python + Streamlit  
- **Machine Learning:** scikit-learn  
- **Data Processing:** Pandas, NumPy  
- **Visualization:** Matplotlib / Seaborn  
- **PDF Generation:** ReportLab / FPDF
